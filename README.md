# 📸 Click2Album — האלבום שלך, בקליק

**מאות תמונות מהטיול. אלבום מודפס אחד, מושלם. והכל קורה אצלך במכשיר.**

Click2Album הופכת את המשימה המייגעת בעולם — לבחור תמונות לאלבום — לחוויה מהירה, כיפית וחכמה: סווייפ כמו באפליקציית היכרויות, בינה מלאכותית שמנקה, מקבצת ומדרגת בשבילך, ומנוע עימוד שמרכיב אלבום ברמת בית דפוס — אוטומטית.

> 🔒 **פרטיות מוחלטת:** כל התמונות, כל הניתוחים, כל המודלים — רצים בדפדפן שלך. אף ביט לא עוזב את המכשיר. אין שרת. אין ענן. אין חשבון.

## 🧠 מנוע ה-AI — כולו בדפדפן

הלב של Click2Album הוא צנרת ניתוח מרובת-מודלים שרצה כולה client-side:

- **זיהוי כמעט-כפולות** — טביעות אצבע פרספטואליות דו-כיווניות (128-bit dHash) + טביעה מרכזית + **התאמת זום צולבת** שתופסת זום-אין/זום-אאוט של אותה סצנה
- **דמיון סמנטי** — MobileNet embeddings (TensorFlow.js) מזהים "אותה סצנה" גם בזוויות שונות
- **זהות פנים** — ArcFace 512-d (InsightFace, ONNX) עם יישור Umeyama ואשכולות אנשים: תמונות של אנשים שונים לעולם לא יתערבבו, גם על רקע זהה
- **חתימת הנושא הבולט** — U2Net saliency מבודד את האובייקט המרכזי בנופים ומזהה "אותו גשר, אחר זום"
- **דירוג "המוצלחת ביותר"** — NIMA (המודל האסתטי של Google) + זיהוי חיוך/מצמוץ (MediaPipe blendshapes) + מדדי חדות, עם חוקי אמינות (וטו מצמוץ, ספי הכרעה)
- **סינון איכות** — Laplacian sharpness, היסטוגרמות בהירות, חתימות צבע

הכל נשמר ב-IndexedDB: אפשר לסגור באמצע, לפתוח מהאוטובוס, ולהמשיך בדיוק מאיפה שעצרת.

`React 18` · `TypeScript` · `Vite` · `TensorFlow.js` · `ONNX Runtime Web (WASM)` · `MediaPipe` · `pdf-lib` · `IndexedDB` · `RTL-first i18n`
